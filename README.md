## 三条容易被忽略的限制

**退款窗口是 3 天加 10GB，两个条件同时满足才行。** 3 天内且用量不超过 10GB，可以全额退到账户余额，或者每笔扣 10 元手续费原路退回；超出任何一个条件，就只能按比例扣掉已用部分退到余额，而**余额不可提现**。10GB 听起来不少，按 5Mbps 推流算，一小时就吃掉约 2.2GB，四个多小时就见底。拿它做小时级的直播压力测试，很可能测试没做完，全额退款窗口先关了。

**热门款经常断货。** 英国和德国的入门款最抢手，有时库存直接显示 0。看中了就先下单，等补货的周期不好预测。

**延迟是官方页面口径，别当承诺。** 韩国三网 80–120ms、日本联通移动 60–80ms、美国 150–200ms。晚高峰都有波动，美国双 ISP 架构的丢包控制相对好一些。官方页面另称在线率维持在 99.9% 以上，故障按 1:2 补偿，中断 1 小时补 2 小时时长。

## 常见问题

**买来能直接当梯子用吗？**
不能。VPS 交付的是一台服务器和一组 IP，访问 TikTok 要自己在服务器上搭代理节点，再用手机或电脑连过去。这一步和买任何一台 VPS 一样，需要一点动手能力。

**续费会不会突然涨一截？**
两个码都标为循环有效，续费按同一折扣走。第一次付款时确认订单页已经显示折后金额，别等到续费才发现码没生效。

**怎么付钱，有汇率损失吗？**
支付宝、信用卡、PayPal 都可以，标价是澳元。支付宝按实时汇率扣人民币；信用卡可能另收货币转换费，具体看发卡行。

**一台 VPS 能挂几个号？**
套餐页没有写账号数上限。行业里比较稳的做法是一个 IP 对应一个账号环境，同一 IP 挂多个号的风险要自己承担。

**直播卡顿一定是带宽不够吗？**
不一定，抖动大、出口 IP 不干净、DNS 解析到别处，都会造成同样的现象。买之前先用 ipleak.net 之类工具核对 IP 归属地和 DNS 是否落在目标国家，比单纯加带宽有用。
